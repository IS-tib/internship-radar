### How it works

A Python scraper hits the public job-board APIs of the companies in `companies.json` (Greenhouse, Lever, Ashby), filters for intern/co-op roles in software, data/ML, other technical fields, and product, and regenerates this file. A GitHub Action runs it on a schedule and commits the changes. To add a company, add its board token to `companies.json`.
