### How it works

`scraper.py` (Python standard library only) calls the public job-board APIs of every company in `companies.json` — **Greenhouse, Lever, Ashby, Workday, and SmartRecruiters** — concurrently, then merges a wide-net **community feed** for companies not on that list, filters everything for intern/co-op roles in software, data/ML, other technical fields, and product, tags each with its real posting date and target term, dedupes, and regenerates this file. A GitHub Action runs it every two hours and commits any changes.

### Sources & credit

Direct-from-board scraping is first-party. The wide-net feed is the community-maintained [vanshb03/Summer2027-Internships](https://github.com/vanshb03/Summer2027-Internships) list — merged and deduped against direct hits so nothing shows twice. Credit and thanks to that project and the Pitt CSC / Simplify ecosystem it builds on.

### Add a company

For Greenhouse/Lever/Ashby, append `{ "name": "...", "ats": "greenhouse|lever|ashby", "token": "..." }` — the token is the board slug in the careers URL (`boards.greenhouse.io/<token>`, `jobs.lever.co/<token>`, `jobs.ashbyhq.com/<token>`). For Workday, use `{ "name": "...", "ats": "workday", "host": "tenant.wdN.myworkdayjobs.com", "site": "CareerSiteSlug" }` — both parts are visible in the company's myworkdayjobs.com URL. Open a PR.
